# ระบบบันทึกพัสดุยาเสพติด

จัดทำโดย **ด่านตรวจยานพาหนะชุมพร**

แอพบันทึกและวิเคราะห์พัสดุที่เกี่ยวข้องกับยาเสพติด ใช้งานผ่านเบราว์เซอร์ ไม่ต้องติดตั้ง ไม่มีเซิร์ฟเวอร์
บันทึกเลขพัสดุ ผู้ส่ง ผู้รับ เบอร์โทร รูปภาพ แล้วเชื่อมโยงหมายเลขที่ซ้ำกันเป็นกลุ่มเครือข่ายให้อัตโนมัติ

## วิธีเปิดใช้

1. ดาวน์โหลดโปรเจกต์ (Code → Download ZIP) แล้วแตกไฟล์
2. ดับเบิลคลิก `index.html` เปิดด้วย **Chrome** หรือ **Edge** (รุ่นใหม่)

ไม่ต้องต่ออินเทอร์เน็ตเพื่อใช้งาน (ปุ่มเปิดแผนที่/ลิงก์ภาพภายนอกเท่านั้นที่ต้องใช้อินเทอร์เน็ต)

## ความสามารถ

- **บันทึกพัสดุ** เลขพัสดุ บริษัทขนส่ง วันที่ วันส่งมอบ ผู้ส่ง ผู้รับ ที่อยู่ ลูกค้า (ผู้ฝากส่ง) เลขบัตรประชาชนผู้ฝากส่ง
  ประเภทสินค้า น้ำหนัก ขนาดกล่อง ค่าขนส่ง ของกลาง และแนบรูป/ไฟล์ได้ไม่จำกัดจำนวน
- **ค้นหา** จากเลขพัสดุ ชื่อ เบอร์โทร ที่อยู่ ลูกค้า เลขบัตร ของกลาง พร้อมไฮไลต์คำที่พบ กรองตามช่วงเวลา/ของกลาง/ขนส่ง
- **นำเข้าข้อมูล** จากข้อความผลค้นหาพัสดุ (วางแล้วแยกข้อมูลให้เอง) และจากไฟล์ **Excel (.xlsx)** / **CSV**
  รวมถึงช่วงเซลล์ที่คัดลอกจาก Excel ระบบจับคู่ชื่อคอลัมน์ให้อัตโนมัติ เปลี่ยนเองได้
- **กราฟเชื่อมโยง** แสดงหมายเลขเป็นกล่องพัสดุ เส้นเชื่อมผู้ส่ง → ผู้รับ ซูม เลื่อน ลากจัดตำแหน่ง ค้นหาหมายเลข บันทึกเป็นภาพ PNG
- **กลุ่มเครือข่าย** จัดกลุ่มหมายเลขที่เชื่อมถึงกัน (เบอร์โทร / เลขบัตรประชาชน / ชื่อ / ที่อยู่ เดียวกัน) ตั้งชื่อเครือข่ายได้
- **ส่งออก** รายการพัสดุและตารางหมายเลข เป็น CSV · **สำรอง/กู้คืน** ข้อมูลทั้งหมดรวมไฟล์แนบ

## ความเป็นส่วนตัวของข้อมูล

- ข้อมูลทั้งหมดเก็บ **ในเบราว์เซอร์ของเครื่องที่ใช้งานเท่านั้น** (IndexedDB) ไม่ส่งขึ้นอินเทอร์เน็ต ไม่ใช้บริการภายนอก
- ล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะไม่ติดไปด้วย — ใช้เมนู **สำรองข้อมูล** เป็นประจำ
  แล้วเก็บไฟล์สำรองไว้ในที่ปลอดภัย
- **ห้ามนำไฟล์ข้อมูลคดี** (ไฟล์สำรอง Excel CSV รูปภาพ) มาเก็บไว้ในโปรเจกต์นี้หรือขึ้น GitHub
  (`.gitignore` กันไฟล์ชนิดที่พบบ่อยไว้ให้แล้ว แต่ควรตรวจก่อน commit ทุกครั้ง)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าจอและไอคอนทั้งหมด |
| `styles.css` | รูปแบบการแสดงผล (โทนเหลือง–ดำ รองรับโหมดมืดและมือถือ) |
| `app.js` | การทำงานหลัก: ฟอร์ม ค้นหา นำเข้า ส่งออก สำรอง |
| `parser.js` | แปลงข้อความผลค้นหาพัสดุเป็นรายการ |
| `sheet.js` | อ่านไฟล์ Excel/CSV และจับคู่คอลัมน์ |
| `network.js` | วิเคราะห์เครือข่ายและวาดกราฟ |
| `db.js` | เก็บข้อมูลในเบราว์เซอร์ (IndexedDB) |
| `util.js` | ฟังก์ชันช่วย (เบอร์โทร ชื่อ วันที่ พ.ศ. ไฮไลต์) |
| `logo.png` | ตราสัญลักษณ์ที่แสดงในแอพ |

ไม่มีขั้นตอน build และไม่พึ่งไลบรารีภายนอก แก้ไฟล์แล้วรีเฟรชเบราว์เซอร์ (Ctrl+F5) ได้เลย
